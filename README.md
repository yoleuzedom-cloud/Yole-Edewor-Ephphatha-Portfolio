# Yole-Edewor Ephphatha — Personal Portfolio

Responsive blue-and-black personal portfolio for **Yole-Edewor Ephphatha**, founder of Orbit AI.

## Features
- Responsive mobile, tablet, and desktop layout
- About, skills and interests, projects, and contact sections
- Featured Orbit AI project card
- Mobile navigation and subtle scroll-reveal animations
- No build tools or package installation needed

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Choose **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for the published site link to appear in the Pages section.

## Customize
Edit `index.html` for text and links, `style.css` for appearance, and `script.js` for interactions.

Never commit API keys, passwords, or other secrets to a public repository.
